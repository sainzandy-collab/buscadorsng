# Senigalia — Matching Olfativo v2.0

App interactiva de fragancias con panel de administración protegido por clave.

## Features

- 🔍 Buscador por perfume, código (Donna X115), marca, nota o categoría
- 🧴 242 fragancias con foto, precio y link a senigalia.com
- 💜 Pirámide olfativa (Salida / Corazón / Fondo)
- 📊 Matching con % de afinidad y perfil olfativo
- 📄 Compartir fragancia como PDF imprimible
- 📱 PWA instalable en iPhone

### Panel Admin (⚙️ con clave)
- 🎨 Cambiar color de marca
- ✏️ Editar fragancias (foto, texto, link, notas, precio, todo)
- ➕ Agregar nuevas fragancias
- 🗑️ Eliminar fragancias
- 💾 Backup y restauración JSON
- 🔑 Cambiar clave de administración

## Setup

```bash
npm install
npm run build
```

## Deploy en Vercel

1. Subir a GitHub
2. Conectar en vercel.com → Deploy automático

## Clave por defecto

La clave inicial del panel admin es: `password`

Cambiala desde el panel de admin una vez que ingreses.
